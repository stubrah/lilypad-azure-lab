# Lily Pad Living

Starter website for a transitional / sober-living housing concept.

## Stack
- HTML, CSS, and browser JavaScript
- Azure Functions (Node.js programming model v4)
- Azure SQL Database
- Managed identity for passwordless Function-to-SQL access

## Goals
- Learn Git and GitHub workflow
- Build and ship a clean first version
- Deploy to Azure Static Web Apps
- Practice Azure administration with a fake-data resident intake workflow

## Azure lab

Start with [docs/AZURE-LAB.md](docs/AZURE-LAB.md). The lab creates a separate
resource group and ends by deleting it so nothing is left running overnight.

> Training only: never submit real resident, health, financial, recovery, or
> identifying information to the lab environment.
